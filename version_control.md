##Version control()

**git config --global user.email "me@example.com"**
This sets my email address for Git.
Git attaches this email to every commit I make.

**git config --global user.name "My name"**
This sets my name.
Git shows this name on my commits.


**git init**   
Initialising in the current repository.

**git staging**
**git add** disk_usage.py adds a single file to the ones to be committed.
**git status** checks if their are new commits or noo.

**git commit** this labels the change ur making a adds it.
**git push** this pushes the files to github.
